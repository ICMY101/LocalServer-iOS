# 本地服务器 · LocalServer for iOS

**把 iPhone 变成一台随身的网页服务器。** 放入 HTML、CSS、JS、图片、视频等文件，一键启动，就能在本机浏览器或同一 Wi-Fi 下的任何设备上访问。

适合这些场景：

- 在手机上运行和调试前端项目、H5 页面、静态网站
- 在会议室或教室里，用手机给大家演示网页，不需要电脑、不需要外网
- 在电脑和手机之间互传文件：电脑浏览器打开管理页，拖进去就行
- 托管离线文档、电子书、相册、视频等，局域网内随时访问

## 功能一览

### 网站服务

- **静态网站托管**：访问文件夹时自动打开 `index.html`，支持目录列表、自定义 `404.html`
- **单页应用（SPA）**：可选回退到 `index.html`，适配 Vue、React 等使用 history 路由的项目
- **音视频可拖动播放**：支持 HTTP Range 请求和 ETag / 304 缓存验证
- **自动刷新（Live Reload）**：文件改动后，浏览器中打开的页面自动重新加载；采用长轮询，几乎不产生额外请求
- **多网站切换**：把任意文件夹设为网站根目录，在多个项目之间一键切换
- **跨域（CORS）**：可选开启，方便调试前后端分离项目

### 文件管理

- **四种导入方式**：App 内导入文件或文件夹；在电脑浏览器中拖拽上传；从微信、QQ 等 App“用其他应用打开”；通过系统「文件」App 直接管理
- **zip 自动解压到独立文件夹**：兼容 Windows 打包的中文（GBK）文件名，自动跳过 `__MACOSX` 等多余文件，并防止 zip 中的 `../` 路径越界写入
- **手机上直接编辑**：新建、编辑 HTML / CSS / JS 等文本文件，重命名、删除、分享
- **搜索与排序**：按名称、修改时间、大小排序，列表 / 网格两种视图

### 电脑端管理

在同一 Wi-Fi 下的电脑浏览器中打开 `http://手机IP:8080/__admin/`：

- **PIN 码配对**：手机上弹出 6 位配对码，在电脑上输入即可。每个浏览器只需配对一次，可在手机上随时取消
- 拖拽上传文件、整个文件夹或 zip，每个文件单独显示上传进度
- 浏览、搜索、下载、重命名、删除文件，新建文件夹
- 支持深色模式，手机和平板浏览器也能使用

### 访问与连接

- 显示本机、Wi-Fi、个人热点地址，附带二维码，其他设备扫码即可访问
- **Bonjour 固定地址**：尽量解析出 IP 变化后仍可使用的 `.local` 地址
- 所有网页都在系统浏览器（Safari 等）中打开，效果与真实访问完全一致

### 后台运行与省电

iOS 会在 App 进入后台约 30 秒后将其挂起。“后台保活”让服务器在后台继续工作，同时尽量省电：

- 只在 App 位于后台时播放静音音频，回到前台立即停止；与其他 App 的声音混合，不会打断音乐
- 设定时间内（默认 15 分钟）没有设备访问，就自动停止保活
- 使用较大的音频缓冲，减少唤醒 CPU 的次数；后台时不刷新界面
- 被电话、闹钟打断后自动恢复

## 安装

本项目通过 GitHub Actions 在云端 macOS 上自动编译，每次推送都会生成新的安装包。

1. 打开仓库的 **Actions** 页面，进入最新一次成功的 “Build IPA” 运行，在底部 **Artifacts** 中下载 `LocalServer-版本号-build构建号`，解压得到 ipa。推送 `v*` 标签时，ipa 也会发布到 **Releases** 页面。
2. 安装包没有签名，需要用自己的 Apple ID 签名后安装。在 Windows 或 Mac 上可以使用 [Sideloadly](https://sideloadly.io) 或 [AltStore](https://altstore.io)。
3. 安装后在 iPhone 上：
   - **设置 › 通用 › VPN 与设备管理** 中信任你的 Apple ID
   - **设置 › 隐私与安全性 › 开发者模式** 中开启开发者模式，并重启手机
   - 首次打开 App 时允许 **本地网络** 权限

> 使用免费 Apple ID 签名的 App 有效期为 7 天，到期后重新安装即可，网站文件和设置不会丢失。

## 技术实现

- **语言与框架**：Swift 5、SwiftUI，最低支持 iOS 16
- **HTTP 服务器**：基于 Network.framework 从零实现的 HTTP/1.1 服务器，支持 keep-alive、Range、条件请求、大文件流式收发；网络收发在串行队列，请求处理在并发队列，大文件上传或解压时不影响其他访问
- **安全**：路径穿越防护、隐藏文件屏蔽、管理接口防跨站请求（自定义请求头 + 不放行 CORS 预检）、PIN 配对（一次性配对码、失败锁定、令牌仅保存 SHA-256 哈希）
- **依赖**：唯一的第三方库是用于解压 zip 的 [ZIPFoundation](https://github.com/weichsel/ZIPFoundation)
- **工程**：使用 [XcodeGen](https://github.com/yonaskolb/XcodeGen) 根据 `project.yml` 生成 Xcode 工程
- **测试**：单元测试与集成测试在 CI 的 iOS 模拟器上运行，集成测试会启动真实的服务器，端到端验证静态文件、上传、配对、解压、自动刷新等功能

### 项目结构

```
LocalServer-iOS/
├── project.yml                      # XcodeGen 工程描述
├── Info.plist
├── .github/workflows/build-ipa.yml  # 云端编译、打包 ipa、运行测试
├── LocalServer/
│   ├── App/                         # 入口与标签页
│   ├── Server/                      # HTTP 服务器、路由、Live Reload、电脑端管理接口与页面、PIN 配对
│   ├── Model/                       # 设置、文件存储、zip 解压、日志统计、网络地址、Bonjour、后台保活
│   ├── Views/                       # 服务主页、文件页、设置页、配对弹窗、导入面板、编辑器、视觉规范
│   └── Assets.xcassets
└── Tests/                           # 单元测试与集成测试
```

### 本地开发

需要一台装有 Xcode 的 Mac：

```bash
brew install xcodegen
xcodegen generate
open LocalServer.xcodeproj
```

在 Xcode 中选择设备运行，按 ⌘U 运行测试。

## 注意事项

- **请保持“需要配对码”开启**，否则同一局域网中的任何人都能通过 `/__admin/` 上传或删除文件
- 配对通过普通 HTTP 完成，可以防止同一网络中的其他人随手访问，但无法防止网络抓包；在不信任的公共 Wi-Fi 下，建议关闭“电脑网页管理”或“允许局域网访问”
- 局域网地址不是 HTTPS，网页中的摄像头、定位、Service Worker 等功能在其他设备上访问时会被浏览器限制；在本机用 `127.0.0.1` 访问不受影响
- “后台保活”通过播放静音音频实现，适合自用；若要上架 App Store，需要移除此功能
- iOS 17 起系统不再向 App 提供设备主机名，`.local` 地址在部分网络下可能无法解析
